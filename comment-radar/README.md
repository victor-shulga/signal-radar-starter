# Комент-радар: радар навколо LinkedIn

Закрита сторінка у вашому Cloudflare з двома вкладками:
- **«Коментарі»**: свіжі дописи потрібних людей і готовий текст коментаря вашим голосом;
- **«Хто реагує»**: люди під вашими дописами й дописами конкурентів, клієнти й ліди окремо.

Публікує людина. Система нічого не пише в LinkedIn і пароля від нього не просить.

Час: встановлення 2–3 години. Далі 15–20 хвилин на день на коментарі й 20 хвилин щопонеділка на розбір людей.

## Як це працює

```
Щоранку (будні, 10:00):
CRM (клієнти й ліди) + ваші списки + пошук за темами
        ↓
HarvestAPI: свіжі дописи за 40 годин
        ↓
Claude відбирає дописи й пише коментарі вашим голосом
        ↓
D1 у вашому Cloudflare → сторінка → ви публікуєте руками

Щопонеділка:
ваші дописи + дописи конкурентів → реакції й коментарі → групи → «Хто реагує»
```

Комп'ютер о 10:00 має бути ввімкнений. Якщо запуск не відбувся, сторінка покаже жовтий рядок.

## Requirements & integrations

| Integration | Used for | Required? | Auth/setup |
|---|---|---|---|
| Claude Code (застосунок або CLI) | пише коментарі, запускається за розкладом | так | підписка |
| HarvestAPI | дописи, реакції, коментарі, профілі, пошук за темами | так | `bash scripts/save_key.sh harvest` |
| Cloudflare Workers + D1 | сторінка і база | так | `npx wrangler login` |
| Cloudflare Access | вхід лише з пошт вашого домену | так | Zero Trust → Access → Applications |
| Twenty | клієнти й ліди автоматично | ні | `bash scripts/save_key.sh twenty` |
| HubSpot чи інша CRM | клієнти й ліди | ні | вивантаження CSV → `import_targets.py` |
| python3, node | скрипти й wrangler | так | python3 є на Mac, node ставиться окремо |

Стелі витрат у `config.json`: $0,9 на ранковий запуск і $5 на понеділковий збір. Це максимум близько $40 на місяць. Стелі $0,9 вистачає приблизно на 160 профілів за ранок.

## Файли

| Файл | Що робить |
|---|---|
| `config.example.json` | автор, конкуренти, голос, ринки, групи, запити, ліміти. Скопіюйте в `config.json` |
| `PROMPTS.md` | три завдання для Claude: перша збірка, щоденний запуск, п'ятничний розбір |
| `scripts/daily.sh` | ранковий збір |
| `scripts/twenty_sync.py` | клієнти й ліди з Twenty |
| `scripts/import_targets.py` | клієнти, ліди й свої списки з CSV (для HubSpot і будь-якої CRM) |
| `scripts/fetch_posts.py`, `scripts/topic_fetch.py` | свіжі дописи й нові автори |
| `scripts/engagers.py` | хто реагує, щопонеділка |
| `scripts/check_activity.py` | хто публікує, раз на місяць |

Ключі лежать у `scripts/*.env` з доступом лише для вас. У git їх не додавайте.

## Встановлення

Команди виконуйте у своєму терміналі, у теці `comment-radar`. Ключі вводьте лише в запит термінала, не в чат Claude.

**Крок 1. Перевірка.**
```bash
python3 scripts/selftest.py      # selftest ok
cp config.example.json config.json
```

**Крок 2. Ключі.** Зареєструйтесь на harvestapi.io (тариф Starter).
```bash
bash scripts/save_key.sh harvest
bash scripts/save_key.sh twenty   # лише якщо у вас Twenty
```

**Крок 3. Налаштування.** Заповніть у `config.json` усі поля з `___`:
- `author`: ваш профіль;
- `competitors`: компанія, людина, посилання. Конкурент продає ту саму роботу тому самому покупцю. Беріть людину, яка пише хоча б двічі на місяць: якщо засновник мовчить, беріть керівника продажів;
- `proof_numbers`: 5–8 реальних чисел, які можна назвати вголос. Це найважливіше поле: коментар без чисел читається як загальні слова, а інших чисел система не напише;
- `groups`, `markets`, `topics.queries`: під свій ICP.

**Крок 4. Клієнти й ліди.** З Twenty вони приходять самі. З HubSpot чи іншої CRM вивантажте CSV з колонками «ім'я, компанія, linkedin» і запустіть:
```bash
python3 scripts/import_targets.py clients.csv --list clients
```
Людина без посилання на LinkedIn у підказки не потрапить. Скрипт скаже, скільки таких.

**Крок 5. Ваші контакти.** LinkedIn → Settings & Privacy → Data privacy → Get a copy of your data → Connections. Файл приходить на пошту протягом доби. Покладіть `Connections.csv` у теку, завдання 1 завантажить його саме. Серед своїх контактів, з якими було листування, за місяць публікують помітно більше людей, ніж серед знайдених пошуком (у моїх замірах 38% проти 14%).

**Крок 6. База.**
```bash
cd site
npx wrangler login
npx wrangler d1 create comment-radar
# database_id з відповіді впишіть у site/wrangler.toml
npx wrangler d1 execute comment-radar --remote --file=schema.sql
```

**Крок 7. Вхід.** Zero Trust → Access → Applications → Add application → Self-hosted. Адреса: піддомен вашого сайту. Правило: дозволити пошти вашого домену. З застосунку візьміть Application Audience (AUD) Tag і назву команди, впишіть у `site/wrangler.toml`.

**Крок 8. Сторінка.**
```bash
npx wrangler deploy
```
У воркері: Settings → Domains & Routes → та сама адреса. Адресу на workers.dev вимкнено навмисно, бо вона йшла б повз вхід. Перевірте в приватному вікні: має з'явитися вхід Cloudflare, без нього сторінка відповідає 403.

**Крок 9. Перша збірка.** Відкрийте теку в Claude і вставте завдання 1 з `PROMPTS.md`. Воно збере списки, дасть три дописи для звірки з LinkedIn і скаже, скільки коментарів на день реально вийде. Звірте кількість реакцій очима: якщо розбіжність більша, ніж можуть дати приховані профілі, далі не йдіть.

**Крок 10. Розклад.** У Claude: «Постав щоденну задачу на будні о 10:00 із завданням 2 з PROMPTS.md і задачу на п'ятницю о 16:00 із завданням 3». Перший запуск зробіть кнопкою Run now.

## Правила коментаря

Вони вже вписані в завдання для Claude. Перевіряйте за ними, коли правите.
- 25–60 слів, один абзац, мова допису.
- Конкретика: число, строк, інструмент, приклад без назви клієнта.
- Покупцям показуєте, що знаєте їхній день. Жодної пропозиції.
- Переписуйте, якщо бачите «great post», переказ допису, рекламу, посилання, обіцянку ROI або назву клієнта.
- Остання перевірка: чи відповів би автор? Два змістовні коментарі кращі за вісім ввічливих.

Темп: 5–15 коментарів на день, одному автору не частіше ніж раз на 7 днів (стежить система). Після двох коментарів людина вас уже бачила: додавайте в контакти без нотатки, сторінка показує таких у блоці «Кого вже прогріли».

Не починайте лист фразою «бачив вашу реакцію на допис». Людина не знає, що це хтось записує. Візьміть тему допису як привід.

## Як це йде в аутріч

`engagers.json` після понеділкового збору = сигнал інтенту. Покупців (групи `clients` і `icp`) заведіть у CRM: дубль людини визначайте за посиланням на LinkedIn, дубль компанії за доменом. Одна людина за тиждень дає один сигнал з вагою 4 і терміном 14 днів.

## Готово, коли

- [ ] Сторінка відкривається на вашому домені, у приватному вікні без входу даних не показує
- [ ] У `config.json` немає `___`, у конкурентів щонайменше 5 профілів із дописами за місяць
- [ ] Три дописи звірено з LinkedIn
- [ ] Підказки з'являлись 5 робочих днів поспіль без вашого запуску
- [ ] Вкладка «Хто реагує» оновилась у понеділок сама
- [ ] Покупці потрапляють у CRM сигналом, без дублів людей

**Впроваджено, коли** ви публікуєте щонайменше 5 коментарів на день два тижні поспіль, а покупці зі сторінки дістають дотик протягом тижня.
