# Запит для Claude Code

Скопіюйте в Claude Code, відкритий у цій теці, і підставте свою картку радара.

```
Ось картка мого радара: [вставте заповнену radar-card.md].

1. Знайди в Apify Store актор під це джерело і поясни, скільки коштує 200 записів.
2. Склади config.json за зразком config.example.json: поля fields мапни на назви полів, які реально віддає актор (спершу зроби пробний запуск на 20 записах і покажи мені один запис).
3. Запусти python3 radar.py config.json і покажи state/<name>_signals.csv.
4. Перевір кожен сигнал: дата з джерела, посилання відкривається, домен компанії правильний, цитата доводить проблему. Що не проходить, допиши в stop_words і запусти ще раз.
5. Постав радар на розклад (/schedule) з частотою з картки.
```
